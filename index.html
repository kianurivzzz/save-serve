Мгновенное SSH-подключение к серверам

Save Serve — расширение для VS Code, которое позволяет сохранять данные серверов и мгновенно подключаться к ним через SSH, не выходя из редактора кода.

Открой Visual Studio Code

3

Введи ext install save-serve

4

Нажми Enter

Terminal 
ext install save-serve

Или просто найди "Save Serve" в маркетплейсе VS Code

Как использовать

  1. Нажми на иконку Save Serve в левом сайдбаре VS Code
  2. Нажми на кнопку + чтобы добавить новый сервер
  3. Заполни информацию о сервере:
    • Имя сервера – понятное название для отображения в списке
    • Хост – IP-адрес или домен
    • Порт – по умолчанию 22
    • Имя пользователя – логин для подключения
    • Способ аутентификации:
      • По паролю – введи и сохрани пароль
      • По SSH-ключу – выбери файл ключа и пароль от ключа, если есть
  1. Открой боковую панель Save Serve в VS Code
  2. Найди нужный сервер в списке
  3. Просто нажми на сервер – VS Code мгновенно откроет терминал с SSH-подключением
  4. Готово! Теперь ты можешь работать с сервером прямо из VS Code

Организация серверов

Редактируй или удаляй группы через контекстное меню

Безопасность

Save Serve использует встроенное в VS Code защищённое хранилище для хранения конфиденциальных данных серверов:

Windows

Windows Credential Manager

macOS

Keychain

Linux

libsecret

Все учётные данные надёжно шифруются и никогда не передаются третьим лицам.

Часто задаваемые вопросы

Какое лучшее SSH-расширение для VS Code?

Save Serve — одно из лучших бесплатных SSH-расширений для Visual Studio Code. Оно позволяет сохранять данные серверов, организовывать их в группы и подключаться в один клик. В отличие от других расширений, Save Serve предлагает кастомные иконки, цветовое кодирование серверов, горячие клавиши и безопасное хранение учётных данных через системный keychain.

Как управлять SSH-серверами в VS Code?

Установи Save Serve из маркетплейса VS Code, нажми Ctrl+P и введи "ext install save-serve". Расширение добавит боковую панель, где можно добавлять, редактировать, удалять и организовывать SSH-серверы. Группируй серверы по проектам или окружениям, назначай иконки и цвета для быстрой идентификации, используй Ctrl+Alt+C для быстрого подключения.

Как подключиться к SSH-серверу из VS Code без ввода команд?

Save Serve избавляет от необходимости вводить SSH-команды вручную. Просто добавь данные сервера один раз. Хост, порт, логин, способ аутентификации, а затем кликни по серверу в боковой панели — мгновенно откроется терминал с активным SSH-подключением. Можно также использовать Ctrl+Alt+C для быстрого поиска и подключения.

Save Serve бесплатный? Безопасный?

Да, Save Serve полностью бесплатный и имеет открытый исходный код, лицензия MIT. Безопасность — главный приоритет: все учётные данные шифруются через системный keychain — Keychain на macOS, Windows Credential Manager на Windows, libsecret на Linux. Пароли и SSH-ключи никогда не хранятся в открытом виде и не передаются третьим лицам.

Как сохранить SSH-подключения в VS Code навсегда?

С Save Serve SSH-подключения сохраняются навсегда. Добавь сервер со всеми данными один раз — он останется в боковой панели между сессиями VS Code. Можно также экспортировать конфигурации серверов в JSON для бэкапа или переноса. Расширение поддерживает аутентификацию по паролю и SSH-ключам с паролем от ключа.

Какие расширения VS Code скачать для работы с серверами?

Для управления SSH-серверами и быстрого подключения через терминал — Save Serve. Расширение простое в использовании: сохрани серверы один раз, подключайся в один клик. Работает на всех платформах Windows, macOS, Linux, поддерживает русский и английский языки, и хранит пароли безопасно через системное хранилище.
